# Dimensional Towers (NeoForge 1.21.1)

By AJ. Huge themed boss towers: five floors of spawners, decorated halls and loot chests, then a boss arena
at the top with a trial spawner boss, an ominous-key vault and treasure chests.

## Towers
| Tower | Where | Boss |
|---|---|---|
| Overworld | any overworld biome | Ashen Tyrant |
| Nether | nether | Ashen Tyrant |
| End | end islands | Ashen Tyrant |
| Piglin | nether | Gilded Warlord |
| Frozen | snowy biomes | random melee boss |
| Desert | desert | random melee boss |
| Oak (wood) | forest, flower forest | random melee boss |
| Dark Forest | dark forest | Axe Warlord (Vindicator) |
| Jungle | jungle biomes | random melee boss |
| Swamp | swamp, mangrove swamp | random melee boss |
| Taiga (spruce) | taiga biomes | random melee boss |
| Badlands | badlands biomes | random melee boss |
| Pillager | any pillager outpost biome | Axe Warlord (Vindicator) |

Melee bosses: Ashen Tyrant (wither skeleton), Rotting Colossus (zombie), Bone Archon (skeleton).

## Build
```
gradle wrapper
./gradlew build
./gradlew runClient
```
Requires JDK 21.
